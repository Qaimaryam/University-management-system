# University Management System

A C++-based **University Management System** developed as a group project using Agile project management, Scrum, XP practices, Git, and Continuous Integration.

## Features

Our assigned modules were:

- **Faculty Management** — Manage faculty records and information.
- **Timetable Management** — Manage class schedules and timetable records.
- **Notification Management** — Create and manage university notifications.

## Project Management

- **Jira** — Used for project planning, backlog management, task tracking, and sprint management.
- **Scrum** — Work was organized and completed through sprints, with features divided into user stories and tasks.
- **Team Size** — 2 members, with responsibilities divided across the assigned modules.

## XP Practices

We applied the following **Extreme Programming (XP)** practices:

- **TDD (Test-Driven Development)** — Test cases were written before/alongside implementation.
- **Implementation** — Developed functionality to satisfy the defined test cases.
- **Refactoring** — Improved code structure and readability while preserving functionality.

## Testing & Continuous Integration

The project includes:

```text
testcases.cpp
```

Test cases were used to verify the implemented functionality.

We used **GitHub Actions** for Continuous Integration:

```text
Commit → Build → Run Tests → Verify
```

Every pushed change can be automatically compiled and tested to detect issues early.
